# STOCKAM

STOCKAM est une application web de gestion de stock, de ventes et de caisse pensée pour les commerces en Afrique de l'Ouest. Elle est conçue pour être simple, rapide à utiliser et accessible sur téléphone comme sur ordinateur.

## Présentation

Cette landing page présente les fonctionnalités principales de STOCKAM :
- gestion des produits
- suivi des stocks
- enregistrement des ventes
- gestion des clients et fournisseurs
- comptabilité simplifiée
- tableaux de bord et statistiques
